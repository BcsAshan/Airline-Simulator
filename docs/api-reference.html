Book a seat in ten calls

The Pss engine follows the Navitaire dotREZ Digital API. A session holds one booking in progress; you shape it call by call, then commit it to get a record locator. Every request goes through the gateway at http://localhost:5000.

  • 42 endpoints live
  • 8 services behind one gateway
  • 15 min idle session timeout
  • USD only in Phase 1

The booking journey

    Basics

    Tokens and sessions

    Get a token from POST /api/auth/v1/token/anonymous (web customers) or /token/user (agents). The session ends after 15 idle minutes or on logout, and held seats are released. An expired session returns 401 even if the token is still valid.

    A raw token without Bearer is also accepted.

    Booking in state

    • /booking/… (singular) changes the booking held in your session. No record locator in the URL.
    • /bookings/… (plural) reads a stored booking by record locator.
    • Nothing is saved until commit. After commit you can change it and commit again with PUT.
    • One stateful call at a time per session; a second one waits 5 s, then gets 409.

    Every response has the same wrapper

    { "data": { … } }
{ "data": null }                      // commands
{ "data": null,
  "errors": [ { "code": "nsk:Booking:NoBookingInState",
                "message": "…", "type": "Validation" } ] }

    Formats

    • Enums come back as numbers; send a number or a name ("Male" or 1).
    • Dates: 2026-12-10, 2026-12-1 or ISO. UTC values end in Z; station-local times have no offset.
    • Keyed collections are objects, not arrays: passengers, contacts, faresAvailable.
    • Keys are opaque Base64. The first adult is always MCFBRFQ- (0!ADT).

    Status codes

    CodeWhen
    200Reads, updates, sell (returns the booking), re-commit with PUT
    201Token, contact, payment, first commit — with a Location header
    304Reference data unchanged (If-None-Match matched the ETag)
    400Validation or business rule — most business errors
    401No token, expired session, or an agent-only endpoint
    404Stored booking not found (stateless read)
    409Concurrent call on the session, or the booking changed in another session
    502 / 503A service behind the gateway is down, or the route belongs to a later phase
